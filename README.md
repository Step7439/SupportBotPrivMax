# Бот техподдержки «ИТМеханизатор» для MAX

Чат-бот техподдержки для мессенджера MAX (Bot API: platform-api2.max.ru).

## Возможности

**Пользователи:**
- `/start` — приветствие с логотипом «ИТМеханизатор — Support»
- Кнопки «📝 Заявка / 📊 Статус / ❓ FAQ» (кнопки типа `message`)
- Любое сообщение создаёт заявку

**Модераторы:**
- `/mod` — меню с inline-кнопками: открытые заявки, список модераторов
- У каждой заявки кнопки «💬 Ответить» / «✅ Закрыть»
- Уведомления о новых заявках приходят с кнопками действий
- Добавление/удаление модераторов (последнего удалить нельзя)

## Запуск

1. Создайте бота на [dev.max.ru](https://dev.max.ru) и получите токен.
2. Скопируйте `.env.example` в `.env` и заполните:
   ```
   MAX_BOT_TOKEN=ваш_токен
   OPERATOR_ID=ваш_id_в_MAX
   ```
3. Запустите: `python3 main.py`

Без зависимостей — только стандартная библиотека Python 3.10+.

## Структура

- `bot/max_api.py` — обёртка над MAX Bot API (updates, messages, answers, uploads)
- `bot/bot.py` — роутер событий (long polling через GET /updates, marker)
- `bot/user_handler.py` — сценарии пользователей
- `bot/mod_handler.py` — панель модератора
- `bot/keyboards.py` — inline-клавиатуры (callback / message кнопки)
- `bot/ticket_service.py` — заявки (data/tickets.json)
- `bot/moderator_service.py` — модераторы (data/moderators.json)

## Особенности MAX Bot API

- Токен передаётся в заголовке `Authorization` (query-параметры не поддерживаются)
- Лимит: 2 сообщения/сек на диалог (учтено троттлингом), 30 rps всего
- Inline-клавиатура только под сообщением; reply-клавиатуры нет — «меню»
  сделано кнопками типа `message`
- Медиафайлы: сначала `POST /uploads` → token, потом вложение в сообщении
